## 1. 产品概述

### 1.1 产品定位

fintax_ai 是一款面向中国企业的税务与财务智能咨询系统，通过自然语言处理（NL2SQL）技术，将用户的自然语言查询自动转换为结构化 SQL 查询并执行，实现"零 SQL 基础"的财务数据查询与分析。

### 1.2 核心价值

- **智能查询**：用户用自然语言提问，系统自动生成并执行 SQL
- **多域覆盖**：支持增值税、企业所得税、财务报表、发票、财务指标等 9 大业务域
- **知识整合**：集成税收优惠政策库（1522 条）和法规知识库
- **智能分析**：LLM 驱动的数据解读和综合分析报告生成
- **权限管控**：5 级角色权限体系，企业级数据隔离

### 1.3 支持的业务域

| 业务域 | 覆盖范围 | 数据源 |
|--------|----------|--------|
| 增值税 | 一般纳税人/小规模纳税人申报数据 | 月度申报表 |
| 企业所得税 | 年度/季度申报数据 | 汇算清缴表 |
| 资产负债表 | 企业会计准则/小企业会计准则 | 月度财务报表 |
| 利润表 | 本期金额/本年累计 | 月度财务报表 |
| 现金流量表 | 经营活动/投资活动/筹资活动 | 月度财务报表 |
| 科目余额 | 期初/借方/贷方/期末 | 会计科目明细 |
| 发票 | 进项发票/销项发票 | 发票明细 |
| 财务指标 | 22 个常用财务指标 | 计算生成 |
| 税收优惠 | 1522 条政策 | 本地知识库 |
| 法规知识 | 税务法规/操作流程 | Coze RAG API |

### 1.4 技术栈概览

- **后端**：Python 3.9+、FastAPI、SQLite
- **前端**：React 19、Vite 7、Chart.js
- **AI 引擎**：DeepSeek LLM（deepseek-chat）
- **部署**：支持本地开发和阿里云部署

## 2. 用户角色与权限体系

### 2.1 角色层级

## 3. 功能模块详解

### 3.1 NL2SQL 财务数据智能查询

#### 3.1.1 功能概述

系统的核心功能，通过两阶段 NL2SQL 流水线将用户的自然语言查询转换为 SQL 并执行，支持 9 大财务数据域的查询。

#### 3.1.2 支持的查询类型

**单域查询**：
- 增值税查询："华兴科技2025年1月增值税"
- 企业所得税查询："TSE科技2024年企业所得税"
- 资产负债表查询："创智软件2025年末资产负债表"
- 利润表查询："大华智能制造2025年利润表"
- 现金流量表查询："环球机械2024年现金流量表"
- 科目余额查询："华兴科技2025年1月科目余额"
- 发票查询："鑫源贸易2025年进项发票"
- 财务指标查询："华兴科技2025年资产负债率"

**跨域查询**：
- 对比分析："华兴科技2025年增值税和利润对比"
- 比率计算："计算华兴科技2025年毛利率"
- 差异核对："核对增值税销售额和利润表营业收入"
- 列表合并："列出华兴科技2025年所有税费"

**多轮对话查询**：
- 实体继承："华兴科技2025年1月增值税" → "2月呢" → "3月呢"
- 域切换："华兴科技2025年1月增值税" → "利润是多少"

#### 3.1.3 查询处理流程

```
用户输入 → 意图路由 → 实体预处理 → 执行路径选择 → 结果格式化 → 数据解读
```

**执行路径**：
1. **指标路径**：匹配 22 个预定义财务指标，确定性计算，无 LLM 调用
2. **概念路径**：匹配 326 个预注册财务概念，确定性 SQL 生成
3. **跨域路径**：拆分为多个子域查询，分别执行后合并结果
4. **标准路径**：两阶段 LLM 调用（意图解析 → SQL 生成）

#### 3.1.4 22 个财务指标

| 类别 | 指标名称 | 说明 |
|------|----------|------|
| 盈利能力 | 毛利率 | (营业收入-营业成本)/营业收入×100% |
| 盈利能力 | 净利润率 | 净利润/营业收入×100% |
| 盈利能力 | 营业利润率 | 营业利润/营业收入×100% |
| 盈利能力 | 成本费用利润率 | 利润总额/(营业成本+期间费用)×100% |
| 盈利能力 | ROE | 净利润/净资产×100% |
| 盈利能力 | ROA | 净利润/总资产×100% |
| 偿债能力 | 资产负债率 | 总负债/总资产×100% |
| 偿债能力 | 产权比率 | 总负债/所有者权益×100% |
| 偿债能力 | 权益乘数 | 总资产/所有者权益 |
| 偿债能力 | 流动比率 | 流动资产/流动负债 |
| 偿债能力 | 现金债务保障比率 | 经营活动现金流/总负债 |
| 营运能力 | 总资产周转率 | 营业收入/总资产平均余额 |
| 结构占比 | 流动资产占比 | 流动资产/总资产×100% |
| 结构占比 | 固定资产占比 | 固定资产/总资产×100% |
| 结构占比 | 流动负债占比 | 流动负债/总负债×100% |
| 结构占比 | 营业成本占比 | 营业成本/营业收入×100% |
| 结构占比 | 期间费用占比 | 期间费用/营业收入×100% |
| 结构占比 | 研发费用占比 | 研发费用/营业收入×100% |
| 结构占比 | 进项税额占比 | 进项税额/营业收入×100% |
| 结构占比 | 留抵税额占比 | 留抵税额/营业收入×100% |

#### 3.1.5 三种思考模式

| 模式 | 说明 | 响应时间 | 适用场景 |
|------|------|----------|----------|
| Quick（快速） | 直接返回缓存结果 + 缓存解读 | < 50ms | 重复查询 |
| Think（思考） | 返回缓存结果 + 重新生成解读 | 1-2s | 需要新解读 |
| Deep（深度） | 重新执行完整流水线 | 2-5s | 首次查询/深度分析 |

#### 3.1.6 数据解读

系统自动对查询结果进行 LLM 驱动的专业解读，支持 7 种场景：
- 单指标单期间：合理性评估
- 单指标多期间：趋势分析
- 多指标单期间：分组分析
- 多指标多期间：综合分析
- 计算指标：指标解读
- 跨域数据：对比分析
- 财务指标：EAV 结构解读

### 3.2 税收优惠政策查询

#### 3.2.1 功能概述

查询本地税收优惠政策知识库，包含 1522 条政策，支持 FTS5 全文检索。

#### 3.2.2 查询方式

- 关键词查询："固定资产加速折旧政策"
- 税种查询："增值税优惠政策"
- 主体查询："高新技术企业税收优惠"

#### 3.2.3 搜索策略（四层递进）

1. 结构化搜索（税种 + 主体类型）
2. 主体类型搜索（跨类型匹配）
3. 关键词 LIKE 搜索（多字段 AND）
4. FTS5 全文搜索（兜底）

#### 3.2.4 结果呈现

- 政策列表：标题、税种、适用主体、有效期限
- LLM 摘要：自动生成政策要点摘要
- 原文展示：完整政策内容

#### 3.3.1 功能概述

通过 Coze RAG API 查询外部税务法规和操作流程知识库。

#### 3.3.2 适用场景

- 操作指南："电子税务局申报流程"

#### 3.3.3 数据来源

- Coze RAG API（外部知识库）
- SSE 流式返回

### 3.4 跨路由混合分析

#### 3.4.1 功能概述

多轮对话场景下，当用户混合查询不同类型的数据（财务数据 + 税收优惠 + 法规）时，系统自动触发综合分析，生成税务筹划建议报告。

#### 3.4.2 触发条件

1. 用户启用多轮对话
2. 对话历史包含 ≥2 种不同路由类型
3. 当前查询包含综合分析关键词（"综合"、"匹配"、"建议"、"筹划"、"优化"等）

#### 3.4.3 分析流程

```
历史查询1（税收优惠）→ 提取政策信息
历史查询2（财务数据）→ 提取企业数据
当前查询（综合分析）→ LLM 税务筹划专家 → 生成综合报告
```

#### 3.4.4 报告结构

1. 📊 数据概览
2. ✅ 适用政策
3. ⚠️ 风险提示
4. 💡 税务筹划建议
5. 📈 优化方向
6. 🎯 行动计划

### 3.5 企业画像与报告

#### 3.5.1 企业画像功能

| 维度 | 内容 |
|------|------|
| 基本信息 | 纳税人信息、注册资本、注册地址、经营范围 |
| 资产结构 | 资产负债构成分析 |
| 利润数据 | 利润表关键指标 |
| 现金流量 | 现金流量表汇总 |
| 增长指标 | 同比增长率 |
| 财务指标 | 22 个财务指标 |
| 税务汇总 | 增值税 + 企业所得税税负 |
| 发票统计 | 进销项发票汇总 |
| 研发创新 | R&D 投入、高新资质 |
| 跨境业务 | 进出口业务指标 |
| 合规风险 | 风险评估 |

**评估规则**：8 个核心指标的阈值分级评估

#### 3.5.2 企业画像报告

**报告生成**：
- LLM 驱动的 14 模块综合分析报告
- SSE 流式生成
- 支持打印/PDF 导出

**14 个分析模块**：
1. 企业身份与股权治理
2. 组织与人力
3. 财务表现
4. 业务运营
5. 购销存/供应链
6. 研发创新
7. 税务表现
8. 跨境业务
9. 合规风险
10. 外部关系
11. 数字化
12. ESG
13. 政策匹配
14. 特殊业务

**综合结论**（6 个维度）：
- 经营健康度
- 财务状况
- 税务合规水平
- 涉税风险分级
- 税收优惠筹划
- 管理建议

**报告管理**：

### 3.6 数据管理

#### 3.6.1 数据浏览器

**功能**：交互式浏览企业原始数据

**支持域**（10 个）：
- profit（利润表）
- balance_sheet（资产负债表）
- cash_flow（现金流量表）
- vat（增值税）
- eit_annual（企业所得税-年度）
- eit_quarter（企业所得税-季度）
- account_balance（科目余额）
- purchase_invoice（进项发票）
- sales_invoice（销项发票）
- financial_metrics（财务指标）

**浏览模式**：
- General 模式：扁平宽表视图（最多 500 行）
- Raw 模式：域特定结构化格式（模拟官方申报表布局）

#### 3.6.2 数据质量检查

**检查类别**（5 类）：
1. 内部一致性：勾稽关系检查
2. 合理性：阈值合理性检查
3. 跨表一致性：跨域数据核对
4. 期间连续性：数据缺失检查
5. 完整性：必填字段检查

**检查规则示例**：
- 资产负债表：资产 = 负债 + 所有者权益
- 利润表：营业利润 = 营业收入 - 营业成本 - 税金及附加 - 期间费用
- 跨表核对：利润表净利润 vs 资产负债表未分配利润变动

## 4. 核心数据流转

### 4.1 NL2SQL 流水线全链路

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           用户查询输入                                    │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 意图路由 (IntentRouter)                                                │
│ - Layer -2: 财务数据优先关键词                                          │
│ - Layer -1: 知识库优先关键词                                            │
│ - Layer 0: 纳税人名称匹配                                               │
│ - Layer 1: 优惠/政策/法规关键词                                         │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
                    ┌───────────────┼───────────────┐
                    ↓               ↓               ↓
            ┌──────────┐    ┌──────────┐    ┌──────────┐
            │financial │    │  tax_    │    │regulation│
            │  _data   │    │incentive │    │          │
            └────┬─────┘    └────┬─────┘    └────┬─────┘
                 │               │               │
                 ↓               ↓               ↓
        ┌─────────────────────────────────────────────────┐
        │ 多轮对话检测 (ConversationManager)               │
        │ - Tier 2: 跨路由混合分析检测                      │
        │ - Tier 1: 财务数据多轮实体继承                    │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ 实体预处理 (EntityPreprocessor)                  │
        │ - 相对日期解析                                    │
        │ - 实体提取（纳税人、期间、类型）                   │
        │ - 域检测（9 大业务域）                            │
        │ - 同义词规范化（300+ 映射）                        │
        │ - 视图选择（会计准则/纳税人类型）                   │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ 执行路径选择                                      │
        │ - 指标路径：22 个预定义指标                        │
        │ - 概念路径：326 个预注册概念                       │
        │ - 跨域路径：多域拆分合并                           │
        │ - 标准路径：两阶段 LLM                             │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ 标准路径：Stage 1 意图解析 (IntentParser)         │
        │ - LLM 调用                                        │
        │ - 输出：domain, views, metrics, filters           │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ 约束注入 (ConstraintInjector)                     │
        │ - 生成 allowed_views, allowed_columns             │
        │ - 设置 max_rows 限制                              │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ 标准路径：Stage 2 SQL 生成 (SQLWriter)            │
        │ - LLM 调用（域特定 prompt）                        │
        │ - 输出：可执行 SQL                                │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ SQL 审计 (SQLAuditor)                             │
        │ - 硬阻断：非 SELECT、多语句、危险函数              │
        │ - 软阻断：缺少 taxpayer_id/period 过滤            │
        │ - 域特定规则（EIT 季度视图需 period_quarter）      │
        │ - 失败重试（1 次）                                │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ SQL 执行                                          │
        │ - 参数化查询                                      │
        │ - 失败重试（1 次，含 SQLite JOIN 提示）            │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ 结果处理                                          │
        │ - 显示格式化 (DisplayFormatter)                    │
        │ - 构建 display_data（表格、图表、元数据）          │
        │ - 数据解读 (InterpretationService)                 │
        │ - L1 缓存写入                                     │
        └─────────────────────────────────────────────────┘
                 ↓
        ┌─────────────────────────────────────────────────┐
        │ SSE 流式返回前端                                   │
        │ - event: stage/chunk/done                         │
        └─────────────────────────────────────────────────┘
```

### 4.3 多轮对话数据流

**Tier 1: 财务数据多轮**

```
Turn 1: "华兴科技2025年1月增值税"
  → 提取实体: taxpayer_id=华兴科技, period_year=2025, period_month=1, domain=vat
  → 执行查询 → 返回结果

Turn 2: "2月呢"
  → 继承实体: taxpayer_id=华兴科技, period_year=2025
  → 提取新实体: period_month=2
  → 执行查询 → 返回结果

Turn 3: "利润是多少"
  → 继承实体: taxpayer_id=华兴科技, period_year=2025, period_month=2
  → 切换 domain: profit
  → 执行查询 → 返回结果
```

**Tier 2: 跨路由混合分析**

```
Turn 1: "资产类税收优惠政策有哪些"
  → 路由: tax_incentive
  → 查询本地政策库 → 返回政策列表

Turn 2: "TSE科技2025年末流动资产结构"
  → 路由: financial_data
  → NL2SQL 查询 → 返回资产数据

Turn 3: "TSE可以享受哪些税收优惠，请结合上述数据分析"
  → 检测到 ≥2 种路由历史
  → 检测到综合分析关键词
  → 路由: mixed_analysis
  → 提取 Turn 1 政策 + Turn 2 数据
  → LLM 税务筹划专家 → 生成综合分析报告
```

```
├── metrics/                 # 22个财务指标公式

└── analysis/                # 分析配置
```

### 6.2 扩展指南

#### 6.2.1 添加新财务指标

无需修改代码，编辑 `config/metrics/metric_formulas.json`：

```json
{
  "新指标名称": {
    "label": "新指标",
    "unit": "%",
    "formula": "变量A / 变量B * 100",
    "sources": {
      "变量A": {"domain": "profit", "column": "营业收入"},
      "变量B": {"domain": "profit", "column": "营业成本"}
    }
  }
}
```

#### 6.2.2 添加新数据域

1. **数据库**：创建明细表 + 视图（JOIN `taxpayer_info`，使用 `ROW_NUMBER()` 选择最新版本）
2. **配置**：
   - 更新 `modules/schema_catalog.py`（视图和白名单）
   - 创建 `prompts/stage2_{domain}.txt`
   - 更新 `config/pipeline/domain_prompt_map.json`
   - 添加域检测关键词
   - 添加同义词映射表
3. **代码**：
   - 更新 `entity_preprocessor.py` 域检测逻辑
   - 更新 `sql_auditor.py` 域特定规则
   - 更新 `display_formatter.py` 格式化逻辑

#### 6.2.3 切换 LLM 提供商

修改 `config/settings.py`：

```python
LLM_API_BASE = "https://your-llm-provider.com/v1"
LLM_API_KEY = "your-api-key"
LLM_MODEL = "your-model-name"
```

系统使用 OpenAI 兼容 API，支持任意兼容提供商。
